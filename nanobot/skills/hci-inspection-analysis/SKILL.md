# HCI Inspection Analysis

用于解释巡检扫描结果和生成统一口径的分析结论。

## 分析步骤

1. 先给出总体概览。
2. 再列重点异常和采集失败项。
3. 明确哪些只是推断。
4. 给出可执行的后续建议。

## 输出要求

使用以下结构：

- 概览
- 重点异常
- 可能原因
- 建议动作

## 约束

- 采集失败必须单独说明
- 没有异常时不得强行推导根因
- 高风险动作只能建议，不直接执行
