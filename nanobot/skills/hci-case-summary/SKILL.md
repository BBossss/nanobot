# HCI Case Summary

用于在排障收尾阶段沉淀结构化案例。

## 适用时机

- 问题已基本定位
- 已完成一轮主要证据采集
- 需要生成案例摘要或归档

## 输出结构

- Problem
- Evidence
- Conclusion
- Suggestion

## 约束

- 事实与推断必须区分
- 证据字段优先引用本轮实际采样结果
- 建议字段应包含后续验证或止血动作

## 不适用场景

- 纯问答阶段
- 证据严重不足的早期排查阶段
