## 6. 当前最建议优先推进的任务

如果按当前仓库状态继续推进，建议优先级如下：

1. `G8` 统一执行安全入口设计与实现
2. `G9` `AgentLoop` 策略层迁出
3. `G10` 存储与配置层收口
4. `G3-G6` 4 个 HCI Skill 初稿落地
5. `F1/F3` 真实联调与安全回归

原因：

- 这几项直接决定当前系统是否能从“能用”进入“可长期演进”
- 继续横向加功能的收益已经低于收口收益
