# HCI 排障助手 V1 命令白名单规范

## 1. 目标

本规范用于定义 HCI 排障助手 V1 的命令执行边界，确保系统在生产环境中默认遵循最小权限原则，仅允许受控的只读诊断行为。

本规范的主要目标：

- 明确哪些命令允许执行
- 明确允许的参数范围与使用方式
- 明确哪些命令和行为必须禁止
- 明确哪些操作必须转为人工审批
- 为后续受控诊断工具实现提供安全基线

## 2. 适用范围

本规范适用于以下执行场景：

- CLI 手动排障
- Mattermost 触发排障
- 定时巡检任务
- 历史案例辅助分析中的诊断调用

本规范适用于排障助手模式，不适用于开发者本地调试模式。

## 3. 总体原则

### 3.1 默认拒绝

除白名单明确允许的命令外，其他所有命令默认禁止。

### 3.2 只读优先

仅允许不会修改系统状态、不会修改文件内容、不会重启服务、不会改变权限的只读操作。

### 3.3 模板化执行

模型不得自由拼接任意 shell 命令。所有命令必须由受控工具映射到固定模板后执行。

### 3.4 参数收敛

即使是白名单命令，也必须限制参数种类、输入路径、输出大小和执行范围。

### 3.5 全量审计

所有命令执行请求都必须记录审计信息，包括触发来源、命令模板、参数、执行时间和结果摘要。

## 4. 执行模式分级

V1 将命令执行分为 3 个等级：

- `ALLOW`
  可由系统直接执行的只读命令

- `APPROVAL_REQUIRED`
  命令本身可能有合理用途，但超出默认白名单范围，必须人工确认后才可执行

- `DENY`
  明确禁止的命令或行为，无论何种场景默认不执行

## 5. 允许的命令类别

V1 建议仅允许以下类别命令进入默认白名单。

### 5.1 文件读取类

允许用于读取日志和配置内容的只读命令：

- `cat`
- `tail`
- `head`
- `grep`
- `egrep`
- `sed`（仅限只读打印）
- `awk`（仅限只读过滤/格式化）

#### 约束

- 仅允许读取白名单目录下的文件
- 禁止通过重定向写入文件
- 禁止配合 shell 特性生成新文件
- 单次读取行数和输出字节数必须受限

### 5.2 系统状态查看类

允许查看系统运行状态的只读命令：

- `ps`
- `top`（建议使用非交互模式）
- `uptime`
- `who`
- `w`
- `df`
- `du`（限制目录范围）
- `free`
- `vmstat`
- `iostat`

#### 约束

- 仅允许非交互模式
- 禁止长时间持续输出
- 禁止对全盘执行无边界扫描

### 5.3 日志系统查看类

允许查看系统日志的只读命令：

- `journalctl`

#### 约束

- 必须限制时间窗口，例如最近 N 分钟 / 小时
- 必须限制输出行数
- 禁止无限制导出整库日志

### 5.4 网络状态查看类

允许查看网络基础状态的只读命令：

- `ip`
- `ss`
- `netstat`
- `ping`（可选）

#### 约束

- 仅允许状态查看子命令
- `ping` 必须限制目标与次数
- 禁止扫描型网络行为

### 5.5 容器/虚拟化状态查看类

如现场环境需要，可按需允许有限的只读子命令：

- `virsh`（仅限只读查询子命令）
- `kubectl`（仅限 `get` / `describe`，且需限制资源范围）

#### 约束

- 仅允许明确枚举的只读子命令
- 禁止 `exec`、`apply`、`delete`、`patch`、`restart` 等变更型动作

### 5.6 文本处理辅助类

允许用于格式化和筛选结果的只读命令：

- `cut`
- `sort`
- `uniq`
- `wc`

#### 约束

- 仅作为已有只读命令的结果后处理
- 禁止组合形成对大规模目录或文件的无边界扫描

## 6. 允许的目录范围

V1 必须定义可读取路径白名单。建议默认只允许以下目录：

- `/var/log`
- `/opt/logs`
- `/var/lib/...`（仅对明确指定的只读诊断文件开放）
- 项目定义的诊断输出目录

### 6.1 路径原则

- 默认拒绝任意路径
- 仅允许配置中显式列出的路径前缀
- 禁止访问敏感凭据目录
- 禁止访问用户私钥、token、密码文件

### 6.2 明确禁止的敏感路径示例

- `~/.ssh`
- `/root/.ssh`
- `/etc/shadow`
- `/etc/sudoers`
- 各类包含明文凭据的配置目录（除非明确脱敏并单独授权）

## 7. 参数限制规则

### 7.1 输出限制

每次命令执行必须设置输出上限：

- 最大读取行数
- 最大匹配条数
- 最大返回字节数

建议默认值：

- 单次日志读取不超过 2000 行
- 单次搜索结果不超过 100 条
- 单次命令输出不超过 256 KB

### 7.2 时间窗口限制

涉及日志查询时，优先使用时间窗口而不是全量扫描：

- 最近 5 分钟
- 最近 30 分钟
- 最近 1 小时
- 最近 24 小时

默认禁止无限时间范围查询。

### 7.3 文件范围限制

不得允许模型对任意目录进行递归扫描。必须收敛为：

- 指定文件
- 指定目录下有限文件
- 预先定义的日志目标

### 7.4 非交互限制

所有允许的命令必须在非交互模式下运行，禁止：

- 持续等待输入
- 打开 TTY UI
- 进入交互式会话

## 8. 需要人工审批的场景

以下场景即使命令本身不是明确禁止，也必须人工审批：

- 访问白名单之外的新路径
- 输出范围超出默认限制
- 执行非常规诊断命令
- 试图读取可能包含敏感信息的配置文件
- 试图执行跨主机相关命令

审批结果应可审计，并建议记录：

- 谁批准
- 批准时间
- 批准范围
- 有效期（如适用）

## 9. 明确禁止的命令与行为

### 9.1 文件写入与修改类

默认禁止：

- `rm`
- `mv`
- `cp`
- `touch`
- `tee`
- `echo > file`
- 任意 `>`、`>>` 重定向写入
- `sed -i`

### 9.2 权限与账户变更类

默认禁止：

- `chmod`
- `chown`
- `chgrp`
- `useradd`
- `usermod`
- `passwd`

### 9.3 服务与系统控制类

默认禁止：

- `systemctl restart`
- `systemctl stop`
- `systemctl start`
- `service restart`
- `reboot`
- `shutdown`
- `kill`
- `pkill`

### 9.4 网络风险行为

默认禁止：

- 端口扫描
- 大范围探测
- 任意外联下载
- 未受控代理转发

### 9.5 远程执行类

V1 默认禁止：

- `ssh`
- `scp`
- `rsync`（跨主机）
- 任意远程 shell

如后续需要跨主机能力，应通过单独的受控采集工具实现，而不是直接放开远程命令。

### 9.6 容器与编排变更类

默认禁止：

- `kubectl exec`
- `kubectl apply`
- `kubectl delete`
- `kubectl patch`
- `docker exec`
- `docker rm`
- `docker restart`

## 10. 建议的受控工具映射

V1 不建议把白名单直接暴露给模型，而应通过受控工具封装。

建议抽象为以下工具：

- `diagnose_log_read`
- `diagnose_log_search`
- `diagnose_system_status`
- `diagnose_network_status`
- `diagnose_preset_check`

每个工具内部使用固定模板映射到底层命令，例如：

- `diagnose_log_read`
  - 允许：`tail`, `head`, `cat`

- `diagnose_log_search`
  - 允许：`grep`, `egrep`, `awk`, `sed`

- `diagnose_system_status`
  - 允许：`ps`, `uptime`, `df`, `free`, `vmstat`, `iostat`

- `diagnose_network_status`
  - 允许：`ip`, `ss`, `netstat`

## 11. 审计要求

每次执行至少记录：

- 请求 ID
- 时间
- 触发来源（CLI / Mattermost / 定时任务）
- 用户标识
- 工具名
- 命令模板名
- 参数摘要
- 实际读取路径
- 输出摘要
- 执行结果（成功 / 拒绝 / 审批中 / 失败）

建议记录目录：

- `workspace/audit/`

## 12. 违规处理策略

当模型请求超出白名单边界时，系统应：

1. 拒绝执行
2. 返回明确原因
3. 提示允许的替代方式
4. 记录审计日志

不得出现“静默降级执行”或“部分放行但未提示”的行为。

## 14. V1 后续待细化项

后续仍需继续细化的内容包括：

- 每条命令的精确参数白名单
- 允许读取的具体日志路径清单
- 特定 HCI 环境下的只读专用命令模板
- 审批流程与审批记录格式
- 不同部署环境下的路径差异映射
